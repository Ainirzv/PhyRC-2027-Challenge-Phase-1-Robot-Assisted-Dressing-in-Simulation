
# PhyRC 2027 — Phase 1: Robot-Assisted Dressing in Simulation

Development repository for experimenting with robot-assisted dressing policies in the PhyRC 2027 simulation challenge.

## Project Overview

This project explores policy development for simulated robotic dressing tasks, including data loading, policy inference, and behavior-cloning experiments.

## Repository Structure

- `policy.py` — Policy implementation and inference entry point
- `zero_policy.py` — Baseline policy
- `data_loading.py` — Dataset loading utilities
- `participant/` — Participant policy and behavior-cloning training code
- `examples/` — Example policy implementation
- `run.sh` — Script for running the project
- `src/PhyRC_Sim/` — Simulation environment code

## Current Work

- Teleoperation demonstration collection
- Dataset preparation for behavior cloning
- Initial policy implementation and evaluation
- Iterative testing in the simulation environment

Follow the official PhyRC challenge instructions for installing the required simulator, dependencies, and evaluation environment.
